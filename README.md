# Survey Quality Hub | منصة تحليل الجودة

نسخة بدون AI لتحليل المقررات واستبيانات الطلاب والموظفين، بواجهة عربية وإنجليزية وترتيب: تحليل جديد، لوحة النتائج، التحليلات المحفوظة، التصدير.

## المعالجة والتكلفة

تقرأ الواجهة الجديدة الملفات وتحسب النتائج وتنشئ Excel وPowerPoint وWord داخل Web Worker في **متصفح المستخدم**. لا تستدعي `/api/export` أو خدمة AI أو تحويل مدفوعة. PDF يُحفظ من نافذة طباعة التقرير. إنشاء التقارير لا يستهلك CPU الخاص بخادم Cloudflare؛ تبقى حدود الاستضافة وذاكرة الجهاز قائمة.

حتى 60 ملفًا في الدفعة بالتتابع، و16 MB لكل ملف، و50 ألف استجابة في Excel. الإلغاء يُبقي النتائج المكتملة قبله محفوظة.

## المدخلات والتحليل

- Excel: ورقة `RawData` بعناوين `Q1` و`Q2`… وصف لكل استجابة. تختار المستخدمة نوع الاستبيان وسنة التقرير.
- CES: Q1–Q16 بمقياس 1–5، وQ17–Q19 مفتوحة. الإيجابية للدرجات 4 و5. أولوية المقرر عندما تقل إيجابية Q15 عن 60%.
- الاستبيانات الأخرى ومنها PLO: تُراجع أنواع الأسئلة والمقياس قبل التصدير. الأسئلة التصنيفية ليست درجات.
- المتوسطات موزونة بالإجابات الصالحة. الفراغات والنصوص وخارج المقياس مستبعدة ولا تُحوّل إلى صفر. لكل سؤال مقام مستقل.
- دمج الاستبيانات يتطلب تطابق السنة والقسم والنوع والأسئلة والمقياس؛ يُرفض تداخل مجموعات المستجيبين.
- Word: نموذج تقرير المقرر الذي يتضمن Course Title وCourse Code والدرجات وجدول CLO وRelated PLOs Code والمستهدف والفعلي.
- نتائج CLO المرتبطة بـPLO قياس مباشر منفصل عن رضا استبيانات PLO/CES. لا يُحسب متوسط برنامج دون أوزان معتمدة.
- اختلاف مجموع الدرجات عن المكتملين يظهر كتنبيه دون تعديل المصدر. حالات الطلبة قد تتداخل ولا تُجمع مع الدرجات.
- القوة والضعف مشتقتان من الحسابات. خطة التحسين اقتراح قائم على قواعد للمراجعة؛ لا يُختلق تنفيذ سابق أو مسؤول أو موعد معتمد.

## التقارير والمقارنات

يمكن اختيار الملفات وترتيبها. PowerPoint يستخدم الهوية الأصلية المستخلصة من القالب بعد إزالة المحتوى الخاص، ورسومًا وجداول قابلة للتحرير. Word يعرض النصوص والجداول وبيانات الرسوم. Excel يتضمن تفاصيل الأسئلة والدرجات والنواتج والتعليقات وجودة البيانات والتوصيات. PDF يعرض الرسوم والجداول عبر معاينة الطباعة.

في المقارنة السنوية تربط المستخدمة كل نتيجة محسوبة بصفها الصحيح مع اختيار النطاق والمقياس وتراجع المعاينة. لا يُفترض تطابق أسئلة مختلفة أو أن نسب الرضا تساوي المتوسطات.

سنوات 2022–2026 وخلاياها وصيغها ثابتة. تُضاف السنة التالية فقط في عمود جديد **يمين الأعمدة المستخدمة** دون تحريك الملاحظات أو مراجع الرسوم الأصلية. تبقى الرسوم الأصلية كما هي، والصفوف غير المربوطة فارغة للسنة الجديدة. يُرفع المصنف الناتج عند إضافة السنة التالية. الاختبارات تتحقق من إضافة 2027 ثم 2028 وبقاء القيم والصيغ والأجزاء الأصلية.

## الحفظ والخصوصية

الواجهة الجديدة تحفظ النتائج في IndexedDB على الجهاز والمتصفح الحاليين دون مزامنة تلقائية. يمكن تنزيل نسخة JSON احتياطية واستعادتها. مسح بيانات الموقع دون نسخة احتياطية يفقد الحفظ المحلي. الملف الأصلي يبقى مؤقتًا في الذاكرة لإعادة الحساب؛ بعد إغلاق الصفحة يلزم اختياره مجددًا والتحقق من تجزئته.

لم تُحذف بيانات Cloudflare D1 السابقة أو migrations. يمكن استيرادها من التحليلات المحفوظة بهوية المتصفح السابقة. مسارات API القديمة باقية للتوافق؛ عملياتها القديمة ما زالت على الخادم. الواجهة الجديدة لا تستخدمها للتحليل أو التصدير. هذا الإصدار لا يغير جدول الإنتاج.

النتائج والنسخ الاحتياطية قد تتضمن تعليقات مفتوحة. الملفات الأصلية والمرفقات الخاصة غير مضمّنة في Git أو الموقع ولا تُرسل إلى AI.

## التطوير والتحقق

Node.js 24 وpnpm 11.19.0:

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm typecheck
pnpm lint
pnpm test
pnpm build
node scripts/browser-worker-smoke.mjs
```

اختبار العامل المبني يشغّل حزمة الإنتاج بمتغيرات متصفح دون Node Buffer للتحقق من XLSX/PPTX/DOCX. يمكن تعيين `COURSE_DIR` إلى مجلد مرفقات خاص لاختبار نماذج المقررات محليًا. المرفقات لا تُضمّن في الاختبارات المنشورة. `work/` و`outputs/` مستبعدان من Git.

## النشر

المشروع متصل بـGitHub وCloudflare Workers Builds. GitHub Actions يتحقق من الأنواع وLint والاختبارات والبناء؛ نشر Cloudflare لفرع `main` مستقل. يجب متابعة نتيجة الفحص والنشر معًا؛ البناء المحلي لا يثبت النشر.

Binding القديم `DB` يشير إلى `survey-quality-seetah-db` لاستيراد الأرشيف. لا تعدلي migration مطبقة. الإصدار الحالي لا يتطلب migration جديدة أو مفتاح AI.
